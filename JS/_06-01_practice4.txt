1단계 — 배열에서 값 하나 꺼내기

먼저 이것만 해보세요. 다른 건 다 지우고요.

document.write(subjects[0]);

화면에 이렇게 나옵니다.

HTML,웹 페이지 구조

두 개가 같이 나왔죠? subjects[0]은 값 하나가 아니라 ['HTML', '웹 페이지 구조'] 라는 묶음이기 때문입니다.

2단계 — 묶음에서 한 개만 꺼내기

묶음에서 하나만 꺼내려면 대괄호를 한 번 더 씁니다.

document.write(subjects[0][0]);   // HTML
document.write(subjects[0][1]);   // 웹

숫자가 두 개인 이유는 이겁니다.

subjects[0][1]
          ↑  ↑
          │  └─ 그 줄에서 몇 번째 칸
          └──── 몇 번째 줄

숫자는 0부터 셉니다. 첫 번째가 0, 두 번

직접 숫자를 바꿔가며 눌러보세요.

subjects[1][0]   // CSS
subjects[2][0]   // JavaScript
subjects[2][1]   // 동적 기능 추가

3단계 — 두 개를 붙이기

+ 로 글자를 이어붙일 수 있습니다.

document.write(subjects[0][0] + ': ' + subjects[0][1]);

HTML: 웹 페이지 구조

가운데 ': ' 는 콜론과 빈칸입니다. 이걸 안 넣으면 HTML웹 페이지 구조 처럼 딱 붙어버려요.

4단계 — 세 줄 다 하기

3단계를 세 번 복사하면 되긴 합니다.

document.write(subjects[0][0] + ': ' + s
document.write(subjects[1][0] + ': ' + subjects[1][1] + '<br>');
document.write(subjects[2][0] + ': ' + subjects[2][1] + '<br>');

결과는 정답입니다. 먼저 이걸로 화면에 잘 나오는지 확인해 보세요.

그런데 보시면 앞 숫자만 0 → 1 → 2 로 바뀌고 나머지는 똑같죠. 이럴 때 쓰는 게 for 입니다.

5단계 — for로 줄이기

for (let i = 0; i < 3; i++) {
    document.write(subjects[i][0] + ': '
}

i 자리에 0, 1, 2가 차례로 들어가면서 같  에서 손으로 복사했던 걸 컴퓨터가 대신하는 거예요.

i < 3 은 나중에 i < subjects.length 로 바꾸면 좋습니다. 과목이 5개로 늘어나도 숫자를 안 고쳐도 되니까요.
